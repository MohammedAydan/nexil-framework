هذا المجلد هو **التوثيق العربي الكامل** لـ Nexis Framework الإصدار `1.0.0`. صُمّم ليكون مرجعًا عمليًا للمطور الذي يريد فهم الفريمورك من الداخل، وبناء تطبيقات حقيقية به، اختبارها، تحسين أدائها، وتأمينها قبل النشر.

> هذا التوثيق يشرح السلوك الموجود في المستودع الحالي، وليس تصورًا عامًا عن فريمورك مختلف. عند وجود فرق بين هذا الدليل وإصدار آخر، يجب الرجوع إلى الإصدار الذي تستخدمه وإلى تعريفات TypeScript في الحزمة المعنية.

## مفاهيم أساسية

Nexis هو فريمورك TypeScript يركز على **HTML أولًا**، و**SSR/SSG**، و**التفاعلية القابلة للاستئناف**. الصفحة تُرندر على الخادم إلى HTML، ولا تُرسل JavaScript لتلك الصفحة إلا إذا احتاجت إلى تفاعل. عند التفاعل، يحمل العميل الجزء المطلوب فقط، ويستعيد الحالة المصرّح بها عبر `ScopeRef` بدل إعادة تشغيل تطبيق كامل في المتصفح.

| المفهوم           | المعنى العملي                                                       |
| ----------------- | ------------------------------------------------------------------- |
| Route             | ملف صفحة داخل مجلد `src/routes` يتحول إلى مسار URL                  |
| Render mode       | طريقة إخراج الصفحة: static أو server أو ISR                         |
| ScopeRef          | تمثيل آمن وموسوم لقيمة أو Signal أو Store أو Action قابلة للاستعادة |
| Lazy handler      | معالج تفاعل يُبنى في chunk منفصل ويُحمّل عند الحاجة                 |
| Action            | وظيفة خادمية تُستدعى عبر endpoint آمن من نموذج أو عميل              |
| Production server | خادم `@mohammedaydan/serve` الذي يخدم build النهائي                 |
| Build artifact    | ملفات HTML وCSS وJavaScript والوسائط الناتجة من عملية البناء        |

## سياسة الأمثلة

الأمثلة تستخدم TypeScript وJSX. قد تحتاج إلى تعديل أسماء المسارات حسب بنية مشروعك. لا تنسخ أسرارًا أو مفاتيح API إلى الملفات؛ استخدم متغيرات البيئة، وطبّق سياسة Origin وCSRF الخاصة بتطبيقك.
