# 22 — قاموس مصطلحات Nexis

| المصطلح                 | المعنى                                                 |
| ----------------------- | ------------------------------------------------------ |
| SSR                     | توليد HTML في وقت الطلب على الخادم                     |
| SSG                     | توليد HTML في وقت البناء                               |
| ISR                     | إعادة توليد HTML بعد مدة مع cache                      |
| Resumability            | استكمال التفاعل من HTML دون Hydration كامل             |
| Hydration               | إعادة تشغيل منطق التطبيق في المتصفح وربطه بـ DOM       |
| ScopeRef                | مرجع موسوم لقيمة أو Signal أو Store أو Action          |
| Signal                  | قيمة قابلة للقراءة والتحديث مع subscriptions           |
| Computed                | قيمة مشتقة تعتمد على Signals أخرى                      |
| Effect                  | وظيفة جانبية تراقب dependencies                        |
| Store                   | حاوية حالة serializable مع selectors وlifecycle        |
| Boundary                | منطقة صغيرة تملك تفاعلًا أو تحميلًا lazy               |
| Lazy chunk              | ملف JavaScript لا يُحمّل إلا عند الحاجة                |
| Bootstrap               | runtime صغير يلتقط الحدث ويستورد chunk                 |
| Action                  | عملية خادمية تستقبل input وتعيد typed envelope         |
| Idempotency             | منع إعادة تنفيذ نفس الطلب أكثر من مرة                  |
| Origin check            | التأكد من أن الطلب جاء من أصل موثوق                    |
| Progressive enhancement | عمل أساسي بدون JavaScript ثم تحسينه عند توفره          |
| RenderNode              | تمثيل مجرد لعنصر أو نص أو شجرة قابلة للرندر            |
| RouteRecord             | تعريف route الناتج من اسم الملف                        |
| Adapter                 | طبقة تربط العقد العام ببيئة Node أو Deno أو Cloudflare |
| Feed                    | RSS أو Atom لعرض تحديثات الموقع                        |
| Canonical               | الرابط الأساسي المقصود لصفحة                           |
| JSON-LD                 | بيانات منظمة بصيغة JSON داخل Head                      |
| OG card                 | صورة المشاركة الاجتماعية Open Graph                    |
| Variant                 | نسخة صورة بصيغة أو عرض مختلف                           |
| Field telemetry         | قياسات من مستخدمين حقيقيين                             |
| Lab metric              | قياس مختبري مثل Lighthouse                             |
| Cache-Control           | سياسة التخزين المؤقت للاستجابة                         |
| Trusted proxy           | proxy يضمن صحة forwarded headers                       |
| Render mode             | static أو server أو ISR                                |
| Scope disposal          | تحرير الموارد عند انتهاء عمر boundary أو route         |
