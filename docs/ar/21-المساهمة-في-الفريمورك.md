# 21 — المساهمة في Nexis Framework

## قبل البدء

اقرأ خريطة الحزم وقرار المعمارية والاختبارات الموجودة. لا تبدأ بتعديل الحزمة التي ظهر فيها الخطأ فقط؛ افهم العقد بين Compiler وRenderer وClient وServer إذا كان التغيير متعلقًا بالرندر أو التفاعل.

## إعداد المستودع

```bash
git clone https://github.com/MohammedAydan/nexis-framework.git
cd nexis-framework
pnpm install
pnpm build
```

استخدم branch منفصلًا، ولا تخلط إصلاحًا صغيرًا مع refactor واسع دون سبب.

## إضافة API

عند إضافة public API:

1. عرّف type واضحًا.
2. طبّق validation عند الحدود.
3. أضف unit tests.
4. أضف integration أو E2E إن تغير السلوك HTTP أو browser.
5. حدث README ومرجع API.
6. أضف release note أو migration note.
7. راجع الأثر على runtime parity والميزانية.

## تغيير Compiler أو Bootstrap

هذا النوع عالي الحساسية. يجب اختبار:

- static route بلا JS.
- interactive route وlazy chunk.
- `data-nx-scope` و`data-nx-on-*`.
- event delegation.
- form submit.
- Deno runtime spec.
- browser console.

لا تعدل assertion القديمة لتخفي اختلافًا في implementation؛ اربط الاختبار بالعقد الحالي الموثق.

## اختبارات الحزم

كل حزمة تملك `src/index.test.ts` غالبًا. شغّل الاختبار من root أو filter:

```bash
pnpm --filter @mohammedaydan/renderer test
pnpm --filter @mohammedaydan/seo test
```

إذا كان التغيير في أكثر من حزمة، شغّل suite root قبل فتح Pull Request.

## التوثيق

اكتب التوثيق بلغة مباشرة، واذكر القيود. أي رقم أداء يجب أن يذكر البيئة وطريقة القياس. لا تدّعِ تشغيل Deno أو Real User Metrics إذا لم تُشغل فعليًا.

## مراجعة أمان

اسأل:

- هل المدخل الجديد غير موثوق؟
- هل يوجد URL fetch أو path join أو HTML injection؟
- هل تغير cache أو origin trust؟
- هل يمكن إعادة تنفيذ العملية؟
- هل ظهرت بيانات في client bundle أو logs؟

## Commit وPull Request

اجعل commit واحدًا متماسكًا. اكتب وصفًا يشرح المشكلة والحل والاختبارات. أرفق screenshots أو benchmark artifacts إذا تغير السلوك المرئي أو الميزانية.

## Definition of Done

المساهمة جاهزة عندما ينجح build وtypecheck وunit وE2E وlint وformat وaudit المناسب، وتكون docs محدثة، ولا توجد conflict markers أو generated files غير مقصودة، ويكون rollback مفهومًا.
