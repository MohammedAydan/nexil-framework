# Nexil v1.0.0 Production GA

**Release date:** 25 August 2026

Nexil v1.0.0 adds the Phase 3 Production GA surface on top of the Phase 2 production-parity baseline. This release is validated by reproducible local gates rather than internet production traffic or search-visibility data.

## Included

The release includes computed-cycle diagnostics, store and selector disposal, component$ ScopeRef capture classification, incremental renderer streaming with abort and backpressure handling, Cloudflare and Deno Fetch handler packages, responsive picture markup, persistent media transform caching, deterministic build-time OG PNG cards, RSS and Atom feeds, validated sitemap alternates and image entries, breadcrumbs and type-specific JSON-LD checks, typed `nexis.config.ts`/JSON loading, declarative redirects, optional LCP/CLS/INP observers, and a local telemetry receiver.

The showcase includes an Astro-style client-JavaScript comparison, seven-route Lighthouse automation, production route/feed/redirect/OG/media evaluation, and the updated v1.0.0 acceptance report.

## Configuration notes

Use `nexis.config.json`, `nexis.config.js`, `nexis.config.mjs`, or a TypeScript `nexis.config.ts` module to declare feed metadata and local redirects. Enable `NEXIS_TRUST_PROXY=1` only when a trusted reverse proxy sanitizes and sets `x-forwarded-proto` and `x-forwarded-host`; otherwise origin checks remain fail-closed. The default idempotency store is process-local and must be replaced for multi-instance production deployments.

## Known gaps

Nexil does not yet serialize arbitrary closures or reconstruct arbitrary functions, provide durable distributed action replay storage, ship provider-specific generated-static edge deployment adapters, provide consent and retention governance for field telemetry, perform complete external Schema.org validation, integrate Search Console, or supply real-user traffic, ranking, backlink, or Core Web Vitals data. These are intentionally documented as follow-up deployment or ecosystem work and are not represented as completed by the local gates.
